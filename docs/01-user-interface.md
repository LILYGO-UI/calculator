# 计算器界面规范

## 竖屏

竖屏保留基础计算器的 4 列、5 行布局：

```text
AC   +/-   %   /
7     8    9   x
4     5    6   -
1     2    3   +
0          .   =
```

实际界面使用标准数学符号。数字键为深灰，功能键为浅灰，运算键为橙色；`0` 键横跨两列。结果靠右显示，字号会根据结果长度在少量固定层级间切换。表达式位于结果上方，超长时只滚动表达式标签。

## 横屏

横屏在左侧增加 6 列科学键区，右侧仍保留基础 4 列键盘。科学键区包含括号、内存、幂、根、对数、三角函数、常量与角度模式。`2nd` 会切换三角和双曲函数的反函数标签。

断点只依据页面容器尺寸：宽度大于高度且宽度不少于 `720px` 时显示科学键区。标准验收视口为：

- 竖屏：`568x1232`
- 横屏：`1232x568`

## 交互状态

- 输入存在时清除键显示 `C`，清空后显示 `AC`。
- 等待右操作数时，当前运算键使用白底橙字表示选中。
- 没有内存值时，`mc` 与 `mr` 文本弱化。
- 除零或函数定义域无效时显示 `Error`；按 `C` 或直接输入数字可重新开始。
- 横竖屏切换不会重置表达式、角度模式、二级功能或内存值。

## 颜色与字体

界面使用纯黑背景，不使用渐变、阴影或装饰容器。主要颜色为：

| 角色 | 色值 |
| --- | --- |
| 页面背景 | `#000000` |
| 数字键 | `#333333` |
| 科学键 | `#242424` |
| 功能键 | `#A5A5A5` |
| 运算键 | `#FF9F0A` |
| 主文本 | `#FFFFFF` |
| 次文本 | `#9B9B9F` |

所有文本通过 `lilygo_ui_font_get()` 获取 AppKit 字体，不随视口宽度连续缩放。

## 验收

UI 改动必须运行：

```sh
cmake --preset host-simulator
cmake --build --preset host-simulator --parallel
ctest --preset host-simulator
```

并检查 `build/host-simulator/calculator-portrait.ppm` 与 `calculator-landscape.ppm`，确认公式、结果、键帽和底部安全区无重叠或裁切。
